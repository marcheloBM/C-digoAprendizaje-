# LaboratorioMultilenguaje

Repositorio que reúne ejemplos prácticos de programación en distintos lenguajes y entornos de desarrollo.  
Su objetivo es servir como referencia y espacio de aprendizaje para proyectos pequeños, pruebas y demostraciones.

[![My Awesome Stats](https://awesome-github-stats.azurewebsites.net/user-stats/marcheloBM?cardType=github&theme=github-dark&fontFamily=&preferLogin=true)](https://git.io/awesome-stats-card)

## 🚀 Lenguajes y entornos incluidos
- **Java** → Web Services, aplicaciones JavaEE/JavaWEB  
- **C#** → Aplicaciones de escritorio y ejemplos básicos  
- **PHP** → Proyectos con XAMPP y MySQL  
- **Android Studio** → Aplicaciones móviles conectadas a bases de datos  
- **Bases de Datos (BD)** → Modelado y consultas en MySQL  

## 📂 Estructura del repositorio
Cada carpeta contiene ejemplos organizados por lenguaje o entorno:
- `/JAVA` → proyectos y ejemplos en Java  
- `/C#` → ejemplos en C#  
- `/PHP` → proyectos PHP con MySQL  
- `/Android Studio` → aplicaciones móviles  
- `/BD` → scripts y modelos de bases de datos
